# Estudo Prático de Git & GitHub

Este repositório foi criado com o objetivo de documentar e consolidar meus conhecimentos práticos em controle de versão utilizando Git e a plataforma GitHub. Aqui organizo notas de estudo, fluxos de trabalho e exercícios práticos desenvolvidos durante o meu aprendizado.

## 🚀 Tecnologias e Ferramentas

* **Git**: Controle de versão local, gerenciamento de histórico e ramificações.
* **GitHub**: Hospedagem de código, colaboração e gerenciamento de repositórios remotos.
* **Markdown**: Formatação e documentação profissional deste arquivo.

## 📂 Conteúdo do Repositório

O projeto inclui arquivos práticos e anotações sobre:
* Configuração inicial do Git (`git config`, `git init`).
* Ciclo de vida de arquivos (`git status`, `git add`, `git commit`).
* Sincronização remota (`git push`, `git pull`, `git remote`).
* Manipulação de histórico e resolução de conflitos.
